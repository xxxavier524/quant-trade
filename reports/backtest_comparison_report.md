### V1.0 局限性

1. **因子独立判断**：各因子作为独立布尔条件简单AND组合，无法处理因子的非线性关系
2. **N型识别粗糙**：仅用scipy极值点检测，缺少回调幅度/时间/企稳/启动的精确约束
3. **无AI排序**：选股结果无法按质量排序，信号间无优先级
4. **无因子监控**：无法检测因子失效，策略可能持续输出低质量信号而不自知
5. **参数硬编码**：阈值分散在各py文件中，调整参数需改代码

## V2.0 回测结果

### 策略升级

V2.0 按规格书完整实现：

| 模块 | V1.0 | V2.0 |
|------|------|------|
| N型识别 | scipy.signal.argrelextrema | 三段式精确数学定义（涨5-30%/回30-62%/企稳+启动） |
| KDJ条件 | J<13 | J<13 + K<30 + D<30 + 底背离 + 周线共振 |
| 量能判断 | 独立因子 | 与N型阶段绑定（红绿柱比/前期异动/末尾缩量） |
| 因子体系 | 8个技术因子 | 15因子（技术5+基本面5+情绪5） |
| 评分模型 | 无 | LightGBM 0-100评分 |
| 预处理 | 无 | MAD去极值+Z-Score+行业中性化 |
| 因子监控 | 无 | IC追踪+状态标记+自动剔除 |
| 回测指标 | 6项 | 8项（+Calmar/Sortino/连续亏损） |
| 参数管理 | settings.py | params.yaml（零硬编码） |
| 前端 | 静态HTML | Streamlit交互面板 |
| 数据存储 | CSV | SQLite三库 |

### V2.0 新增能力

1. **智能排序**：LightGBM对N型候选股进行0-100评分，高分优先

## 结论

- **V1.0** 已完成全部代码和单元测试（15/15通过），可独立运行，适合快速试错
- **V2.0** 在V1.0基础上补齐了规格书要求的精确N型识别、AI评分、因子监控、YAML配置，架构更完整
- **阻塞项**：全量A股数据下载（baostock约需3-4小时），完成后两版本均可产出统计显著的回测结果
- **建议**：数据就绪后优先跑V2.0完整回测；V1.0可用于快速验证单个策略信号质量
