## 二、已实现的实验性因子

### 2.1 北向资金代理因子 (NORTHBOUND_FLOW)

| 属性 | 内容 |
|------|------|
| **来源** | 广发证券《北向选股2.0：因子篇》(2024.5)、国金证券(2024) |
| **方法论** | 量价代理资金流向: flow = volume * log_return * |log_return|; 短期(5D)与长期(20D)累计流入比率差值 |
| **A股IC** | 全市场季频IC均值 5.1%; 行业层面IC 19.72% |
| **ICIR** | 2.7 (年化) |
| **胜率** | 89.3% |
| **多空收益** | 12.8% (年化) |
| **方向** | 正向因子 (流入越多→收益越高) |
| **实现文件** | `alphapulse/factors/experimental/northbound_capital_flow.py` |

### 2.2 特质波动率因子 (IDIOSYNCRATIC_VOL)

| 属性 | 内容 |
|------|------|
| **来源** | 国信证券《隐式框架下的特质类因子改进》(2022)、东吴证券《纯真波动率》(2020)、Ang et al. (2006) |
| **方法论** | 简易: return.std(); CAPM: 滚动回归去Beta后残差波动率; 复合: IVOL+IVR等权 |
| **A股RankIC** | -9.29% (FF3剥离最优)、PCA复合 -8.92% (ICIR -5.04, 胜率92%) |
| **ICIR** | -3.44 (年化) |
| **胜率** | 86% (月度); 复合因子92% |
| **多空月均** | 2.16% |
| **方向** | 负向因子 (低IVOL→高收益; 空头主导, 空头收益占比>70%) |
| **实现文件** | `alphapulse/factors/experimental/idiosyncratic_vol.py` |

### 2.3 换手率分布均匀度因子 (TURNOVER_UNIFORMITY)

| 属性 | 内容 |
|------|------|
| **来源** | 东吴证券《换手率分布均匀度UTD因子》(2024.1)、中信建投《筹码分布因子》(2025.8) |
| **方法论** | 换手率滚动变异系数(CV); 可选极差比法、指数衰减加权、换手偏度 |
| **A股RankIC** | -0.067 (UTD); 对比传统Turn20 IC -0.072 |
| **RankICIR** | -3.99 |
| **胜率** | 77.30% |
| **多空收益** | 20.06% (年化) |
| **方向** | 负向因子 (低均匀度分→筹码稳定→收益好) |
| **实现文件** | `alphapulse/factors/experimental/turnover_uniformity.py` |

### 2.4 分析师盈利修正代理因子 (ANALYST_REVISION)

| 属性 | 内容 |
|------|------|
| **来源** | 华泰证券《分析师预期类因子初探》(2024.12)、国泰君安 |
| **方法论** | 量价代理: 短期-长期动量差 + 放量上涨信号 + 盈利修正稳定性; 三组件加权合成 |
| **A股综合RankIC** | 4.27% (原始数据); 3.99% (盈利修正子因子) |
| **TOP组合年化超额** | 10.55% |
| **指增:** 沪深300/+10.64%; 中证500/+15.48%; 中证1000/+24.73% |
| **相关性** | 与AI量价因子仅0.03 (高度独立) |
| **方向** | 正向因子 (上调→看多) |
| **实现文件** | `alphapulse/factors/experimental/analyst_revision.py` |

### 2.5 大单资金流向因子 (CAPITAL_FLOW_BIG)

| 属性 | 内容 |
|------|------|
| **来源** | 东海证券资金流因子研究 |
| **方法论** | 识别大单日(vol>1.5x均价)→资金流向方向→滚动净流入/总成交量; 大单占比+强度+一致性三组件 |
| **30天IC** | 0.087 (大单, 在所有资金流因子中最强) |
| **IR** | 0.729 |
| **对比** | 大单IC最强; 中单IC 0.055; 特大单IC 0.010 (最弱) |
| **方向** | 正向因子 (大单净流入→看多) |
| **实现文件** | `alphapulse/factors/experimental/capital_flow_big_order.py` |

## 五、使用注意事项

1. **数据要求**: 实验性因子使用标准OHLCV日线数据(open/high/low/close/volume)，无需额外数据源。部分因子有量价代理假设。
2. **因子方向**: IVOL和UTD为负向因子(值越小越好)，北向资金、分析师修正、大单资金流向为正向因子(值越大越好)。在因子合成时需注意方向对齐。
3. **市值依赖**: IVOL在小市值中效果显著更强(中证1000 IC>中证500>沪深300)。
4. **Barra/FF应用**: 可作为Barra CNE6风格因子的本地化补充，或FF5模型的A股特定变量。
5. **量价代理局限**: 无分析师/北向真实数据时使用量价代理，IC会低于原始研报数据(约打6-8折)。
