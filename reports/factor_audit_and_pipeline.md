### 选股决策规则

```
IF 股票被 B1_FORMULA 选中 AND N_STRUCT=0(无N型结构):
    → 主力信号 ⭐⭐⭐

IF 股票被 B1_FORMULA + BRICK_ULTRA 同时选中:
    → 共识信号 ⭐⭐⭐⭐

IF 股票被 B1_FORMULA + BRICK_ULTRA + B1_ENHANCED 同时选中:
    → 强烈信号 ⭐⭐⭐⭐⭐

IF N_STRUCT=1 (出现N型结构):
    → 排除(IC=-0.387反向)
```

### 组合构建规则

```
- 优先选择 3策略共识(⭐⭐⭐⭐⭐)
- 其次 2策略共识(⭐⭐⭐⭐)
- 最多持有5-8只
- 单票≤20%仓位
- 止损-10%，止盈+30%
- N_STRUCT=1的股票排除
```
