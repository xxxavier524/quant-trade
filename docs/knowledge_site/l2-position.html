L2 经典方法 · 第 3 章

仓位与组合：正期望之后，下多大注

本章导读

选股决定赚不赚，仓位决定赚多少、亏多深、能不能活到赚钱那天。 本章讲凯利公式的直觉、为什么实务只用1/4凯利、 以及你系统里"单票≤20%、最多5只、大盘档位调仓"这三条规则的数学出处。

1. 凯利公式：复利最快的下注比例

f* = (b×p − q) / b     b=赔率, p=胜率, q=1−p

下注比例太小浪费优势，太大一次回撤毁掉复利（亏50%要赚100%才回本）。 凯利给出长期复利增长最快的那个点。但它有两个致命前提：你准确知道p和b、你能忍受巨大波动—— 实盘里两个都不成立，所以实务用1/4~1/2凯利：增长牺牲一点，回撤大幅缩小。

类比

开车去机场：理论最快是地板油（全凯利），但任何一个意外就全完。 老司机开八成速度（分数凯利）——慢一点点，但确定到得了。交易是无限局游戏，活着比快重要。

凯利计算器 + 回撤体感
拖动胜率和赔率，看全凯利/半凯利/四分之一凯利的仓位建议和典型最大回撤。
×0.1
注意全凯利的典型回撤——大多数人在-40%时已经弃疗，策略再好也白搭。 仓位的第一约束不是数学，是你的心理承受力。

2. 组合层面：分散与相关性

5只票各20%不等于风险砍成1/5——若5只都是同板块同逻辑（比如全是超跌反弹）， 跌起来一起跌，等于一只票满仓。分散的本质是逻辑分散，不是数量分散。 你的Top50带板块/概念标注，挑票时刻意跨板块，比多拿两只同板块更降风险。

大盘档位是组合的总阀门：个股再好，空头市里也七亏二平一赚—— 先用大盘分定总仓位区间，再在区间内分配个股，自上而下。

在你的系统里
  • 单票≤20%/最多5只：等权下注+逻辑分散的简化实现（约等于保守分数凯利）
  • 大盘仓位建议：多头70-90% / 震荡30-50% / 空头≤10%——量能+知行BS+N型三维定档
  • 回测口径同款约束：settings.py MAX_SINGLE_POSITION=0.20, MAX_HOLDINGS=5
  • 战法持有规则是动态仓位：B2没来→换股（截断时间风险），放飞→减1/3（锁utilities盈利）
本章小结
  • 凯利给出复利最优注码，实务用1/4~1/2（参数有误差+回撤难忍）
  • 分散看逻辑不看数量；同逻辑5只=1只满仓
  • 自上而下：大盘档位定总仓 → 组合内分配 → 个股止损定单笔风险

自测

1. 胜率55%、赔率1.5，全凯利 f* = (1.5×0.55−0.45)/1.5 = 25%。实务建议仓位？
回测算出的55%胜率实际可能是50%——全凯利对参数误差极其敏感，高估时直接变成毁灭机器。
2. 持有5只票：3只锂电+2只光伏，都是"超跌缩量B1"。这个组合的有效分散度接近？
板块相关+逻辑相关双重叠加。新能源板块跌3%时五只大概率全绿，分散是幻觉。
3. 亏损50%后需要涨多少回本？这说明什么？
0.5×2=1。回撤越深回本越难，这就是凯利要打折、空头市要轻仓的根本数学。
