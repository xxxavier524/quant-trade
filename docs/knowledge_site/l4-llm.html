LLM 在量化中的角色：能做什么、不能做什么、怎么用才安全

本章导读

大模型不是水晶球。本章把LLM在量化里的三类靠谱用法和三类不靠谱用法摆清楚， 再拆解你的NL转因子和形态教学两条管线——为什么它们能用，而"让GPT直接选股"不能用。

1. LLM 擅长什么：把自然语言变成结构

LLM的本职是语言到结构的翻译器，不是预言家。在量化里，三个最有价值的用法：

  • NL→因子代码：你写"J<15且缩量到5日均量一半"，LLM输出 compute(df) 函数
  • 研判结构化：把它生成的中文研判强制约束成"评分/狙击点位/止损/风险"五字段JSON
  • 新闻消化：扫公告/新闻，输出"利好-中性-利空"分类标签和影响维度

共同特征：输入有歧义、输出有结构。这是LLM的甜区——人类不喜欢写格式化的东西， 机器又看不懂自由文本，LLM是天然桥梁。

2. LLM 不擅长什么

  • 预测涨跌：它没有市场数据、没有训练目标，输出的是"看起来像分析师的话"，不是预测
  • 数值计算：算KDJ算错很常见——任何数学交给Python，LLM只负责写代码
  • 自我一致性：同一个问题多次回答可能矛盾，必须用结构化输出和程序验证双重锁死

把它当"会写代码的实习生"，不要当"老股神"。判断标准很简单： 这件事如果让一个完全不懂行情、只会写代码的实习生做，行吗？行就交给LLM。

类比

LLM是会十国语言的翻译官，不是预言家。让他翻"低位放量阳"成代码——可以； 让他预测明天涨跌——他给的是文字版彩票，跟瞎猜差不多。 用错地方就像让翻译官当医生开药，看着说得头头是道，全是危险。

3. 你的两条管线：安全链怎么修

NL→因子（factor_gen.py）：

  1. 正则解析器优先（零成本/确定）—— 简单条件不调LLM
  2. 不命中才调 DeepSeek，system prompt 含因子契约+示例+禁止未来函数规则
  3. AST 白名单：只允许 pandas/numpy，禁 import/exec/eval/open/os/__attr
  4. 沙箱冒烟：受限命名空间执行，随机数据跑通+输出类型校验
  5. 落盘到 factors/generated/ 默认禁用，等用户在GUI看胜率验证后手动启用

这条链上LLM只在第二步出现，输出经过三道闸门才能进入系统。 即使LLM写了恶意代码也只能死在第三步——这是LLM安全工程化的标准范式。

形态教学（pattern_teach.py）同样的安全链 + 历史标注验证 + 命中案例K线展示： 你看图确认机器理解对了再启用。机器学的是规则，验证靠人眼——人机协作的甜区。

⚠ 反面教材

常见错误用法：让LLM"看K线图预测涨跌"。它本质是文字模型，看图能力有限且无市场记忆—— 输出的是"它认为分析师该怎么说"，不是真预测。用LLM做研判可以，做信号不行。

4. 成本与节流

DeepSeek 比 GPT-4 便宜约一个数量级，但仍要节流：

  • NL→因子：单次调用，约¥0.05
  • AI研判：每天 Top10 批量一次，v4-flash 批量价 ≈ ¥0.1/天
  • 形态教学：教一个形态约¥0.1，启用后零调用（标注函数是普通Python）

原则：LLM 只在管线的入口（理解需求）出现，运行时的所有计算用普通代码。 这既省钱又确定——LLM调用次数是O(用户操作)而非O(行情数据)。

在你的系统里
  • 客户端 alphapulse/llm/client.py：openai SDK直连 deepseek-v4-pro/flash，不引LangChain（规避Py3.14兼容风险）
  • 研究优化→AI工具：NL→因子表单（不配 KEY 时走正则路径仍可用）
  • 研究优化→ML形态→形态教学：完整闭环，含历史命中案例小K线展示
  • scripts/ai_review.py：每日 Top10 AI研判 markdown，约¥0.1/天
本章小结
  • LLM 是语言→结构的翻译器，甜区是"输入有歧义、输出有结构"
  • 三道安全闸：正则前置、AST白名单、沙箱冒烟；默认禁用待人工启用
  • LLM 只出现在管线入口；运行时用普通代码，省钱且确定

自测

1. 想让DeepSeek "看K线预测明天涨跌"。最理性的态度？
LLM擅长语言到结构、不擅长数值预测。预测交给特征工程+ML，LLM只在管线入口翻译需求。
2. NL→因子安全链里，AST白名单的作用是？
即使LLM被诱导生成 os.system('rm -rf /')，AST校验直接拒收。这是LLM工程化的标配防线。
3. 为什么LLM调用要"O(用户操作)而非O(行情数据)"？
理解需求一次，运行时用普通代码——既省钱又确定，且LLM出错的影响面被钉死在入口。
