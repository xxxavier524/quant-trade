模型评估：AUC 0.545 到底是好是坏？

本章导读

金融ML有自己的成绩单。教科书上0.55的AUC会被笑话， 但在量化里这是好模型——本章讲为什么，以及怎么读你的分位胜率 和特征重要性两张更有用的报表。

1. AUC：教科书指标，金融里要打折看

AUC衡量"模型给正样本的打分能否系统性高于负样本"。0.5=瞎猜，1.0=神。 CV/NLP里常见0.9+，金融市场上0.55-0.60已是顶级——为什么？ 因为市场极度噪杂、参与者都在套利信息，能稳定预测到55%的方向已经是巨大优势。 问题不是"AUC低"，是用错指标：

  • AUC告诉你"全样本排序能力"，而你只交易模型最看好的5%——剩下95%排得对不对你根本不在乎
  • 你真正要的：模型打分Top10%的样本，胜率是多少——这才是实战

2. 分位胜率：量化人该看的指标

把测试集按模型分数排序后切10档（十分位/decile）：

  • Top10%档的胜率 = 模型最看好的票里实际涨了多少
  • Bot10%档的胜率 = 模型最不看好的票里实际涨了多少
  • 两者差距越大，模型越能分得开好坏

你的GBDT：Top10% 48% vs Bot10% 34%，差距14个点——这就是真正可用的信号强度。 AUC 0.545只是"压缩成一个数"的副产品。

类比

豆瓣评分。一部电影综合分7.5（AUC）不如告诉你"打9分以上的1000个人里有80%是文艺片爱好者" （Top10%分位）来得有用——你只关心"我的圈层会不会喜欢"。

分位胜率直方图
拖动"模型强度"，看十分位胜率是怎么从均匀变成阶梯的。差距越大=分得越开。
强度0 = 完全随机的瞎猜模型，十档胜率都贴近基准36%。 强度满 = 完美预测，Top10% 胜率拉到80%+。你的GBDT大约在强度4-5。

3. 可解释性：模型说的话能不能信

除了准不准，还要问"它凭什么判这只票好"。两个工具：

  • 特征重要性：模型在所有树里"用到某特征做切分"的总频次/总收益。 你的Top5是 红肥绿瘦/振幅/QL位置/5日涨幅/量比——和体系认知吻合 → 没学歪
  • 形态贡献：当某只票的ml_score特别高，可以追问"哪些特征把它推上去的" （SHAP值/局部解释）——让模型从黑箱变成"说人话的助手"

当Top特征出现"周二的样本数"这种荒诞列时，立刻警惕：要么数据泄漏，要么模型在抓伪相关。 领域知识互证是可解释AI的核心保护。

在你的系统里
  • 验证报告 models/pattern_gbdt_meta.json：AUC、各分位胜率、特征重要性Top15
  • GUI "ML形态"页可视化：四个KPI卡 + 水平条图(重要性) + 重训按钮
  • 形态教学闭环：模型重训后若教学形态（pt_*）进入Top重要特征 → 弹出提示"教学被采纳"
  • Bot10%胜率34%（接近基准）：模型擅长找好票，找烂票能力一般——符合"过滤而非空头"的设计
本章小结
  • 金融ML上AUC 0.55已是优秀；该看分位胜率而非AUC
  • Top10%胜率-Bot10%胜率 = 真正可用的信号强度
  • 特征重要性+领域知识互证 = 防止模型抓伪相关的最后一道墙

自测

1. 量化模型AUC=0.55，老板拿来对比CV比赛的0.95模型说"垃圾"。该怎么回？
不同领域指标基准完全不同。金融市场有效假说告诉我们：能稳定预测一点点已是异常。
2. 模型Top10%胜率55% vs Bot10%胜率35%。最实用的解读？
分位差距才是信号强度。20个点在金融上是巨大alpha——前提是不在所有样本上下注。
3. 特征重要性榜首是"日期的星期几"，AUC却很高。最该怀疑什么？
缺乏经济学/交易逻辑的特征排第一，几乎必有问题。可解释性是审查模型可信度的核心闸门。
