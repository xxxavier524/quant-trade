L1 量化基础 · 第 2 章

回测与过拟合：不花钱的试错，和最贵的自欺

本章导读

回测是量化的核心能力：把规则放回历史，看"如果当年这么做会怎样"。 但回测也是最容易自欺的环节——本章讲四个大坑，以及你的系统里防住它们的具体机制。 最后用一个真实案例收尾：一个看起来很有道理的想法，是怎么被回测否决的。

1. 四个大坑

坑一：未来函数。信号计算偷看了当时不可能知道的数据。 最隐蔽的形式不是故意作弊，而是粗心：用当日收盘价决定当日开盘买入、指标里混进了 shift(-1)、 周线用了本周未走完的数据。回测无敌、实盘失灵，九成是它。

坑二：幸存者偏差。只用今天还活着的股票池回测历史—— 退市的、暴雷的都被悄悄剔除了，等于只研究"从战场回来的飞机"。

坑三：过拟合。规则记住了历史的噪音而非规律。 症状：参数微调一点结果剧变；规则越改越复杂、每加一条历史收益就涨一点；样本内完美样本外崩盘。

坑四：成本失真。不计滑点和手续费的回测都是童话。 A股小票的冲击成本远比想象大，高频信号在毛收益上赚钱、净收益上亏钱是常态。

类比

过拟合像考前把去年考卷的答案背下来：去年的卷子（样本内）满分， 今年的卷子（样本外）露馅。防法只有一个—— 用没背过的卷子打分，这就是Walk-Forward滚动验证。

过拟合演示：规则越复杂，样本外越惨
拖动"规则复杂度"，看样本内（蓝）和样本外（红）表现的分化。复杂度=参数个数/条件层数。
最优点通常在中等复杂度：太简单学不到规律（欠拟合），太复杂背下噪音（过拟合）。 你的B1只有6个条件、砖型图3个子类型——克制是有意的。

2. 防线怎么修

  • 因果切片：信号只用 ≤t 日数据。你的 replay_screen.py 把数据严格切到回放日，全部指标都是因果算子（rolling/shift正数/ewm）。
  • 时间切分：训练/验证/测试按年份切，绝不随机打乱（详见L3·2）。
  • 黄金回归：你给的47只案例固化成 tests/golden/，任何公式改动必须先过"能复现通达信选股"这一关——这是把正确性锚死。
  • 成本入账：买+0.1%/卖-0.2%滑点+万2.5佣金，验证器同时给毛/净两套数字。
  • 邻域稳健：参数寻优不取单点最优（详见L2·2）。
在你的系统里：一次真实的否决

2026-06-12，从 Sequoia-X 项目学来"RPS相对强度过滤"——逻辑听起来很对： 剔除弱者恒弱的假底。AB回测（6.3万次B1事件）结果：

无过滤 5日净均值 +0.19% → RPS≥40：+0.12% → ≥50：+0.08% → ≥70：+0.01%（单调变差）

否决。原因事后才看清：RPS是动量体系的工具，而B1是超跌均值回归买点，二者逻辑相反。 "听起来有道理"和"数据上成立"是两回事——这就是回测门禁存在的意义。 完整记录在 融合日记#1。

本章小结
  • 四坑：未来函数、幸存者、过拟合、成本失真；未来函数是实盘失灵头号原因
  • 防线：因果切片、时间切分、黄金回归锚定正确性、净收益口径
  • 任何"听起来有道理"的改动都要过AB回测，负结果同样珍贵

自测

1. 策略回测年化60%，实盘三个月亏损。最该先排查什么？
回测与实盘的巨大落差，第一嫌疑永远是未来函数（前视偏差），第二是成本假设。
2. "参数从13改到14，年化从35%掉到8%"，说明什么？
真实规律的参数面是平滑的山丘，不是一根针。一格之差天壤之别=记住了噪音。
3. 用"当前沪深300成分股"回测过去十年的策略，主要问题是？
今天的成分股名单本身就是"未来信息"。正确做法是用每个历史时点的当时成分。
4. RPS过滤被否决的根本原因是？
RPS在它的原生体系（突破/动量）里是好工具；嫁接到均值回归体系水土不服。工具没有好坏，匹配才有。
