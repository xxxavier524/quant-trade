## 0. 知行指标定义（全系统基础）

### 0.1 知行短期趋势线（白线）

```
白线 = EMA(EMA(C, 10), 10)
```

来源：`docs/tdx_formulas/知行趋势线.txt`

### 0.2 知行多空线（黄线）

```
黄线 = (MA(C,M1) + MA(C,M2) + MA(C,M3) + MA(C,M4)) / 4
M1=14, M2=28, M3=57, M4=114   （用户确认值）
```

### 0.3 知行洗盘短线

来源：`docs/tdx_formulas/知行洗盘短线.txt`，参数 **N1=3, N2=21**（用户确认值）

```
短期   = 100*(C-LLV(L,N1))/(HHV(C,N1)-LLV(L,N1))    N1=3，白色
中期   = 100*(C-LLV(L,10))/(HHV(C,10)-LLV(L,10))    黄色
中长期 = 100*(C-LLV(L,20))/(HHV(C,20)-LLV(L,20))    紫色
长期   = 100*(C-LLV(L,N2))/(HHV(C,N2)-LLV(L,N2))    N2=21，红色

四线归零买：短期≤6 且 中期≤6 且 中长期≤6 且 长期≤6
白线下20买：短期≤20 且 长期≥60
白穿红线买：CROSS(短期, 长期) 且 长期<20
白穿黄线买：CROSS(短期, 中期) 且 中期<30
参考线：85 / 30
```

注意：分母是 `HHV(C,N)-LLV(L,N)`（高点用收盘价，低点用最低价），不是常规 KDJ 的 HHV(H)。

### 0.4 砖型图

来源：`docs/tdx_formulas/砖型图.txt`。TDX `SMA(X,N,M)` = `ewm(alpha=M/N)`。

```
VAR1A = (HHV(H,4)-C)/(HHV(H,4)-LLV(L,4))*100 - 90
VAR2A = SMA(VAR1A,4,1) + 100
VAR3A = (C-LLV(L,4))/(HHV(H,4)-LLV(L,4))*100
VAR4A = SMA(VAR3A,6,1)
VAR5A = SMA(VAR4A,6,1) + 100
VAR6A = VAR5A - VAR2A
砖型图 = IF(VAR6A>4, VAR6A-4, 0)

红柱：砖型图 > REF(砖型图,1)（值上升）
绿柱：砖型图 < REF(砖型图,1)（值下降）
```

来源：`docs/tdx_formulas/B1选股公式.txt`

6. MACD DIF > -0.1

## 2. 三大战法

### 战法一：B1/B2/B3（底部挖掘牛票）

- **B1** = 形态与资金共振的底部买点（1.1/1.2 公式）。买入后等主力资金进场，没来 → 及时换股
- **B2** = B1 后的**放量阳线**，确认进入加速通道。没加速 → 换股
- **B3** = B2 后的**缩量阳线且无明显破位**（主力锁仓），确定性更高
- 持有规则：B1/B2 需脱离成本区、股价站上白线；突破后**不跌破白线坚持持有**；只做图形完美的标的

### 战法二：单针下三十（N型上涨标的中的主力洗盘补票）

- 前提：前期走势符合 B1 完美图形（前期可被 B1 选出）
- 信号：知行洗盘短线的**短期线（N1=3）单日下插 ≤30 后快速回收至 ≥80**，当日为形态良好的阳线
- 持有：买入后脱离成本区 3% 以上可持有，按止盈减仓策略减仓

### 战法三：砖型图（短线爆发力），三种子类型

1. **N型起跳**：与 B2 结合，前期洗盘回调结束后第二波拉升起点；红砖 ≥ 前一日绿砖的 2/3，放量阳柱，**最佳位置在黄线附近**
2. **上涨中继**：前期明显拉升后短暂停歇；当日红砖、前1-2天绿砖；中继前1-2天的阴线回调不能跌破前面放量阳线柱的中间位置（最好不破其收盘价）
3. **横盘突破**：3-5天以上横盘（区间总振幅≤15%，约1-2根K线幅度），当日放量突破横盘区间且突破前高

## 3. 多头因子（评分体系正向因子）

关键K（KEY_KLINE）、暴力K（VIOLENT_KLINE）、倍量柱（DOUBLE_VOLUME_BAR）、异动（ABNORMAL_VOL）、**3/4阴量线（新建）**、筹码集中（CHIP_CONCENTRATION）、关键K的A/B/C三节点（KEY_K_ABC）、N型结构（N_STRUCT）、对称结构（SYMMETRIC_STRUCTURE)、主力三波段：建仓波/拉升波/冲刺波（WAVE_IDENTIFIER）、**砖型图四砖一周期（新建）**、填坑出坑（FILL_PIT_EXIT_PIT）、长阴短柱（LONG_YIN_SHORT_COLUMN）

## 4. 空头/卖出信号（持仓管理与回测卖出规则）

- **止损**：跌破买入日最低价下 3-5 个价位，或上一 N 型结构低点下 3-5 个价位（DYNAMIC_STOP_LOSS）
- **放飞**：站上白线后连续 2-3 根中长阳 → 减仓 1/3~1/4（视大盘/板块/个股）；砖型图第四块砖减仓（FLY_AWAY）
- **S1**：波段最高点放巨量阴线，量柱为短期最高且显著高于阳量柱 = 最强卖出（S1_SELL_SIGNAL）。**注意假阴真阳**（阴线但收盘>开盘 = 承接强，可观察）
- **DD**：次日收盘 < 前日最低价；连续两天 DD = DD增强 → 基本清仓（DD_SELL_SIGNAL）
- **跌破趋势线**：跌破白线/黄线可等一天，次日收盘必须站回，否则清仓（TRENDLINE_BREAK）
- **死叉**：白线下穿黄线，或 MACD 下穿零轴

## 5. 零散知识点（增强/过滤因子）

- **5种出货方式**：①加速后天量大阴（S1，辨假阴真阳）②加速后次高点放巨量长阴 ③新高后阶梯放量下跌 ④双头第二波不破前高且顶部放量 ⑤顶部阴量柱持续长于阳量柱（适合大盘股）。盘子越大出货方式越综合
- **牵牛绳**：B1 入场后回调不出 S1、持续在白线上 = 持有依据
- **掉进碗里**：股价处于白线之下、黄线之上区间内出现 B1 买点 = **增强因子**
- **黄线交易价值**：前期无出货痕迹时黄线附近买点反弹率高；趋势股上涨后**第一次回踩黄线不破**的 B1 买点最有价值（前提：前期无 S1、回调无放量）
- **击穿对手盘**：回调末期无量跌破黄线/关键支撑 → 忍一天，次日收回 = 极限洗盘；没收回 = 卖
- **关键支撑价位**：前低（上一 N 型低点）下 3-5 价位、横盘区间下沿、SB1（B1 后几天内的第二个 B1）下沿，破位即止损
- **大哥还在**：前期经常跌破黄线或放量加速下跌破黄线无稳住痕迹 = 主力不控盘，需重新站上黄线才可交易；持续考验黄线不破 = 主力在

## 6. 大盘与板块（Phase 2b）

- **大盘诊断**：量能（成交额 vs MA20/60）、N 型结构（指数级）、知行 BS 点（白线/黄线金叉死叉、站上/跌破）→ 综合分 0-100 + 仓位建议
- **板块评分**：板块量能、板块性质（顺周期/科技/消费/医药/防御/红利）、板块指数相对白线/黄线位置与形态、行业财务与业绩聚合 → 板块排名；个股评分联动加分

## 7. 回测约束

- 滑点：买 +0.1% / 卖 -0.2%；手续费万2.5最低5元；单票 ≤20%，最多5只
- 禁止未来函数：所有指标只用截至当日数据；前向收益仅用于统计验证
- 模糊量（"3-5个价位""形态良好阳线"等）：实现取保守默认并参数化，网格扫描定值后与用户复盘确认
