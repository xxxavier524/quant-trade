## 二、核心架构与关键模块精读

### 2.1 四大模块分层（核心设计哲学：策略与监督分离）

```
FactorBuyBu/   买入因子（突破、回调等，产生候选交易）
FactorSellBu/  卖出因子（止盈止损、N日卖出、闪电卖出）
UmpBu/         裁判系统（对候选交易行使否决权）★精读重点
MLBu/          机器学习基建（封装sklearn）
```

哲学："基础策略保持简单稳定，优化监督模块独立演进"。买卖因子不追求聪明，**聪明放在裁判层**——这避免了把过滤逻辑揉进策略导致的过拟合与不可维护。

### 2.2 UmpBu 目录精读

```
ABuUmpManager.py     # 裁判管理器：注册多个裁判，任一/多数否决则拦截
├─ 主裁 Main 系列（块状决策：聚类否决）
│   ABuUmpMainBase.py    # 主裁基类：训练期实现"失败交易特征聚类"
│   ABuUmpMainDeg.py     # 角度主裁：拟合角度特征(deg_ang21/42/60/252，买点前N日价格线性回归角度)
│   ABuUmpMainJump.py    # 跳空主裁：买点前的跳空缺口特征
│   ABuUmpMainPrice.py   # 价格主裁：买点绝对/相对价格位置
│   ABuUmpMainWave.py    # 波动主裁：买点前波动率特征
│   ABuUmpMainMul.py     # 多因子混合主裁
│   ABuUmpMainFull.py    # 全特征主裁
└─ 边裁 Edge 系列（点状决策：近邻投票）
    ABuUmpEdgeBase.py / EdgeDeg / EdgePrice / EdgeWave / EdgeMul / EdgeFull
```

**主裁原理**（ABuUmpMainBase）：
1. 回测产出全部历史交易（带结果标签：盈利/亏损）
2. 在某一特征子空间（如四个时间窗的趋势角度）对交易做 **GMM 聚类**，component 数扫描多档
3. 找出**失败率超过阈值（如 ≥65%）的簇**，把这些簇的中心和边界存为"危险区"
4. 实盘新信号 → 计算同样特征 → 若落入任何危险簇 → **裁判否决，不下单**

**边裁原理**（ABuUmpEdgeBase）：不做聚类，对新信号在特征空间找历史最近邻交易，按近邻的盈亏做投票，倾向失败则否决。主裁看"块"（区域性失败模式），边裁看"点"（局部相似案例）——两者互补，Manager 可组合多裁判表决。

### 2.3 与常规"ML预测收益"的本质区别

abu 不让 ML 预测谁会涨（难），只让 ML **识别"历史上这种买点长什么样时大概率失败"**（相对容易、样本对齐、可解释——每次否决都能回放出对应的失败簇/近邻案例）。这是防守型ML，目标是提升精确率（precision）而非召回。

## 三、亮点技术拆解

### 亮点1：失败交易聚类否决（主裁）

为什么有效：规则信号（如B1）的失败案例往往集中于少数几种情境（如下跌中继的假底、高位回落途中的J超卖）。在低维可解释特征（趋势角度、波动、价格分位）上聚类，失败情境会成簇。**只否决高失败率簇**意味着拦截是保守的、局部的，不会全局扭曲策略行为。与我们现在"LGBM输出全局胜率分"相比：聚类否决可解释（能指认"你像2023年4月那批失败B1"）、不依赖单一概率阈值。

### 亮点2：拟合角度特征族 deg_ang{21,42,60,252}

买点前21/42/60/252日收盘价做线性回归，取斜率换算角度。四个角度组成"买点姿态向量"：(-5°,-10°,-20°,-30°)是单边下跌抄底姿态，(+5°,-8°,+15°,+20°)是上升趋势回调姿态。**极简但信息密度高**，是描述"底部挖掘上下文"的好特征——比裸价格序列对ML友好得多。

### 亮点3：裁判可插拔表决机制（UmpManager）

多个裁判独立训练、独立否决，Manager 配置组合（任一否决/多数否决）。新裁判上线不动存量——和我们因子注册表(factor_registry)同样的开闭原则，应用到风控层。

## 六、不取的部分及原因

- **abu框架与代码本体**：2019年停更，py2兼容层、自带数据抓取全部过时，GPL-3.0许可也需隔离——只移植算法思想，不抄代码
- **其买卖因子库（突破/均值回归族）**：通用美股风格，不如用户A股战法体系
- **18496组合策略生成**：暴力枚举策略组合容易过拟合，与我们"先验战法+参数网格"路线冲突
- **Elliott波浪/谐波形态模块**：主观形态学，与缠论引入同理由不取，避免话语体系膨胀
