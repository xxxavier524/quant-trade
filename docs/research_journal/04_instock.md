### 2.2 策略实现范式精读（enter.py）

```python
def check_volume(code_name, data, date=None, threshold=60):
    # 放量上涨判定：
    # 1) 当日涨幅 >= 2% 且收盘 > 开盘（阳线）
    # 2) 成交额 >= 2亿（close * volume，过滤流动性差的票）
    # 3) 当日成交量 / 5日均量 >= 2（倍量）
    # 4) 需至少60日历史数据
```

特点：**每个策略 = 一个无状态 `check(code, df, date)->bool` 函数**，跑全市场用多线程 map。简单粗暴但易于"策略超市"式扩展。与我们 `compute(df)->Series` 因子范式相比，它是逐日逐票布尔判定，效率低但语义直白。

### 2.3 选股验证（回测验证）模块

每天选股后，系统自动统计该策略历史信号在 1/2/3/4/5/10/15/20/25/30 日后的涨跌幅分布与成功率，存表并在 Web 端展示——**"策略每日体检报告"**。这与我们 evening_review 思路一致，但它的多周期持有收益矩阵（N日后收益分布）展示更完整。

### 2.4 筹码分布（CYQ成本分布）

按一定回看期内每日成交量在 [low, high] 价格区间均匀/三角分布摊开，叠加衰减（换手率近似筹码转移），输出每个价位的持仓占比曲线，进而计算：**获利盘比例(profit ratio)、平均成本、90%筹码集中度**。底部挖掘语境下，"低位单峰密集+获利盘<10%"是经典的底部确认特征。

### 2.5 数据工程细节

- 东财接口带 Cookie 与代理IP池分散请求（**我们东财被封，正需要这套反限流方案**，但也说明东财源脆弱）
- 多线程+单例共享资源，全市场每日批处理4分钟
- 龙虎榜、资金流向、分红配送等200+维度入库

## 三、亮点技术拆解

### 亮点1：筹码分布算法（我们体系的空白）

原理：维护价格桶向量 `chips[price_bucket]`；每日把成交量按当日K线价格范围分布到桶（三角分布，重心在avg价），同时按换手率 `t` 衰减旧筹码：`chips = chips*(1-t*decay) + new_dist*t`。输出获利盘比例 = 当前价以下筹码占比。**与用户"底部挖掘"逻辑强互补**：B1买点+获利盘<15%+低位单峰密集 → 真底部；获利盘>80%高位密集 → 出货风险（S1辅助）。

### 亮点2：多周期持有收益验证矩阵

每个策略信号统计 N∈{1..30} 日后收益的均值/中位数/胜率，形成"持有期×策略"矩阵。可以直接回答"B1信号最优持有天数"——这是用户战法 B3 锁仓周期的数据依据。

### 亮点3：talib CDL 61形态批量扫描

61种经典K线形态一次性 `talib.CDLxxx` 全算，形态作为离散特征入库。锤头线(CDLHAMMER)、刺透(CDLPIERCING) 等与"单针下三十"族谱接近，可作为LGBM的补充离散特征。

## 五、取精华建议

### 建议1：实现 `alphapulse/factors/chip_distribution.py` 筹码分布因子（最优先）

```python
def compute_chips(df, half_life=60) -> pd.DataFrame:
    """逐日演化筹码桶（向量化：价格桶×日期矩阵，用指数衰减核做加权累计）
    返回每日: profit_ratio(获利盘比例), avg_cost, conc90(90%筹码价格带宽/价格)"""

# 派生因子注册：
# CHIP_PROFIT_LOW: profit_ratio < 0.15  (底部吸筹完成)
# CHIP_SINGLE_PEAK: conc90 < 0.12       (单峰密集)
# 进入0-100评分体系（底部挖掘权重项）+ LGBM特征
```

向量化注意：桶分布可预计算每日三角分布矩阵 `D[t, bucket]`，然后 `chips_t = Σ_{s<=t} D[s]·vol_s·∏(1-turnover)`，用 log 空间 cumsum 实现衰减积。工作量：**2~3天**（含与通达信筹码图对拍验证）。

### 建议2：evening_review 升级为多周期持有矩阵

现有胜率统计扩展为 N∈{1,2,3,5,10,20} 日持有收益矩阵，按策略(B1/B2/B3/单针/砖型)分组，输出最优持有期建议。工作量：**1天**（信号追踪表已有，只加聚合维度）。

### 建议3：吸收其入场阈值做 B2 确认参数对拍

B2"放量阳确认"当前参数 vs InStock 的（倍量≥2×MA5量、成交额≥2亿、涨幅≥2%）进网格搜索对比。工作量：**0.5天**（网格搜索基建已有）。

### 建议4：talib CDL形态批量特征（可选）

`alphapulse/factors/cdl_patterns.py`：一次算61个CDL形态，筛选与B1次日收益IC最高的前10个进LGBM。工作量：**1天**（需装talib，已是InStock依赖说明mac可装）。

## 六、不取的部分及原因

- **MySQL+Web全家桶**：我们已有 CSV+Streamlit，迁移数据库纯属负担
- **东财数据抓取层**：东财接口我们已被封，且其Cookie方案脆弱；继续用 baostock
- **同花顺自动交易**：仅Windows，我们走QMT导出CSV路线
- **逐票check函数式策略范式**：性能差于我们的向量化 `compute(df)->Series`，不倒退
- **打新模块**：与短线战法无关
